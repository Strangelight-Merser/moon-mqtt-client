## 已验证

- 独立 TLS 模块：`third_party/async-tls`（同步自独立仓库
  `Strangelight-Merser/async-tls@0.1.0`），C 前缀
  `strangelight_async_tls_`。`moon.work` 本地链接。
- `moon test --target native`：37 通过。
- Mosquitto mTLS：QoS 1 往返、中间证书链、拒绝矩阵（缺中间证书、
  不受信客户端 CA、过期证书、密钥不匹配、损坏 PEM、加密私钥、
  错误服务器 CA、错误主机名、缺失文件）、双身份并发、证书 ACL
  隔离、broker 重启后重新认证、握手超时后新客户端仍可连接、
  30 次重复连接、CLI 参数校验。原有 TCP / 单向 TLS 仍通过。
- EMQX 5.8.8 固定镜像：原有 QoS 1 / ACL / 重连通过；新增 mTLS QoS 1
  往返与缺证书拒绝通过。
- 独立消费模块：TCP 与 mTLS 本地 workspace 安装通过。
- 四场景演示：`normal` / `lost_puback` / `broker_restart` /
  `controller_restart` 通过。
- Linux CI 已加上 `tests/emqx_interop.py`；macOS/Linux 集成测试会跑
  到新的 mTLS 用例。
