## 审计发现

| 严重程度 | 问题与证据 | 处理 |
|---|---|---|
| P1 | Linux Core `38249472459` 的 native 测试在 `PipeRead._direct_read` 崩溃。`read_session_byte/chunk` 的外层 `alive` 检查与 `with_timeout_opt` 子协程实际读取之间存在调度窗口；其间 session abort 会关闭 transport。新增两个不依赖计时的 FIFO 调度反例分别稳定触发 SIGABRT，与 CI 栈的读取路径一致。 | 在子协程内、调用 reader 前重新检查会话状态；已关闭会话返回 None，仍存活会话的 peer EOF 保留 ReaderClosed。新增第三个回归验证 EOF 语义。修复未修改旧 heartbeat 测试，也没有放宽超时或重试 CI。 |
| P2 | Core/Integration 在源码中途改变后仍能返回 successful；candidate 打包开始后源码变化仍生成有效清单；候选验证只比文件，接受相同文件但不同 commit。临时 Git 仓库反例均在修复前错误成功。 | 所有验收级别记录结束快照并核对 commit/files；打包成功清单产生前核对源码；消费者执行前核对 commit/files，结束再次核对。六项独立回归及新增独立 CI 工作流覆盖此契约。 |

| 未完成验收 | 最终候选的完整双平台 Release、外部逐拨 TCP/TLS/CONNACK 绑定、GPIO 独立物理观测仍缺。 | 保留 Release HOLD；本轮未执行硬件、固件或主机网络操作。 |
